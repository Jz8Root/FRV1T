<details>
<summary>Decode the invisible ink</summary>

Remove the leading emoji and its first U+FE0F. Map U+FE00–U+FE0F to bytes 0–15, and U+E0100–U+E01EF to bytes 16–255. Require ASCII `FRV2`, remove those four bytes, gzip-decompress the remainder with a 256 KiB limit, then decode strict UTF-8. Reject invalid, truncated or trailing data. One final newline is transport whitespace.

Or run `python3 decode.py '🫐.txt'` to print the prompt. The decoder never executes it. [Manifest](manifest.json) records exact hashes and the scope of creative testing.
